# 🌊 Zambales Tourism — Web Application

A full-featured tourism website for the Province of Zambales, Philippines.
Frontend: pure HTML, CSS, and JavaScript. Backend: PHP API — no framework required.

---

## 📁 Project Structure

```
zambales-webapp/
├── index.html               → Homepage (pure HTML)
├── pages/                   → All other HTML pages (no PHP inside!)
│   ├── destinations.html    → Destinations listing (cards loaded from the API)
│   └── contact.html         → Trip inquiry form (submits to the API)
├── api/                     → All PHP backend code lives here
│   ├── destinations.php     → GET  → returns destinations as JSON
│   ├── contact.php          → POST → validates the inquiry form, returns JSON
│   └── config/
│       ├── db.php           → PDO database connection (⚠️ gitignored)
│       └── db.php.example   → Template — copy to db.php and fill in
├── assets/
│   ├── css/style.css        → All styles (CSS variables, layout, animations)
│   ├── js/main.js           → Scroll effects, filter, API fetch, form submit
│   └── images/              → Local images, icons, favicon
├── uploads/                 → User-uploaded images (ensure chmod 755)
├── .gitignore
└── How to run.txt
```

How the pieces talk to each other:

```
HTML pages (frontend)  ──fetch()──►  api/*.php (backend)  ──PDO──►  MySQL (optional)
        ▲                                  │
        └────────── JSON responses ────────┘
```

- `pages/destinations.html` fetches `api/destinations.php` and renders the cards with JS.
- `pages/contact.html` submits the form with JS to `api/contact.php` and shows
  the success / error state from the JSON response — no page reload.

## 🚀 Getting Started

### Requirements
- PHP 8.0+
- MySQL / MariaDB (optional — contact form works without DB by default)
- A local server: [XAMPP](https://www.apachefriends.org/), [Laragon](https://laragon.org/), or `php -S localhost:8000`

### Quick Start

```bash
# Clone / copy the project into your server's web root
cd /Applications/XAMPP/htdocs
# or: cd /var/www/html

git clone <your-repo-url> zambales-webapp
cd zambales-webapp

# (Optional, only needed for the database)
# Copy and fill in the database config
cp api/config/db.php.example api/config/db.php
# Edit api/config/db.php with your credentials

# Start your local server FROM THE PROJECT FOLDER
php -S localhost:8000

####################If you want to open a server from anywhere.
C:\xampp\php\php.exe -S localhost:8000
```

Then open `http://localhost:8000/` in your browser.

⚠️ Note: the pages load data from the PHP API, so always open the site through
the server (http://localhost:8000), not by double-clicking the HTML files.

## 🗄 Database (Optional)

The contact form works out of the box without a database.
To persist inquiries, create a MySQL database and run:

```sql
CREATE DATABASE IF NOT EXISTS zambales_tourism
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE zambales_tourism;

CREATE TABLE inquiries (
  id              INT AUTO_INCREMENT PRIMARY KEY,
  name            VARCHAR(150)  NOT NULL,
  email           VARCHAR(255)  NOT NULL,
  phone           VARCHAR(30)   DEFAULT NULL,
  trip_type       VARCHAR(60)   DEFAULT NULL,
  guests          TINYINT       DEFAULT 1,
  preferred_dates VARCHAR(120)  DEFAULT NULL,
  message         TEXT          NOT NULL,
  created_at      DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;
```

Then uncomment the PDO block in `api/contact.php`.

## 🔌 API Endpoints

| Method | Endpoint                | Description                              |
|--------|-------------------------|------------------------------------------|
| GET    | `/api/destinations.php` | All destinations as JSON                  |
| POST   | `/api/contact.php`      | Submit trip inquiry (form data) → JSON    |

Example responses:

```json
GET /api/destinations.php
{ "success": true, "data": [ { "name": "Anawangin Cove", "category": "beach", ... } ] }

POST /api/contact.php
{ "success": true, "name": "Juan dela Cruz" }
{ "success": false, "errors": ["A valid email address is required."] }
```

## ✨ Features

| Feature | Details |
|---|---|
| **Frontend / Backend Split** | Pure HTML pages + JSON API in `/api` (PHP) |
| **Parallax Hero** | Smooth scroll-based depth effect on hero image |
| **Scroll Reveal** | IntersectionObserver — staggered fade-up on scroll |
| **Destination Filter** | Client-side category filtering with CSS transitions |
| **Drag-to-scroll Gallery** | Mouse drag scroll for the horizontal photo strip |
| **Animated Counters** | Eased number count-up when stats enter viewport |
| **Contact Form** | JS fetch → PHP API validation → success state, no reload |
| **Mobile Navigation** | Full-screen overlay nav for small screens |
| **Responsive Layout** | Mobile-first breakpoints at 768px and 1100px |
